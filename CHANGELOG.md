# Changelog

## 0.1.0-alpha.1 - 2026-10-20

First public, Apache-2.0 desktop source release with fresh GitHub no-reply history.

- Local workspace with CSV/document import, saved reports, chart/table views and
  contributing source-row inspection.
- Loopback model setup, structured JSON requests, bounded dataset-ID recovery and
  explicit publication-window checks.
- Source/type/test/renderer CI, reviewed provenance, locked dependencies and
  local Apple-silicon package/integrity-check commands.
- Reviewed hosted-interface GIF and MP4 using a QA/sample social CSV.

Source only. No signed/notarized installer, completed desktop social OAuth,
outgoing desktop email, bundled model or automatic self-improvement is included.
The hosted demo is not evidence of those unavailable desktop capabilities.
